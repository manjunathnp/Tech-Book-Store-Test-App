New to API testing? Start here (4 tiny steps)

  1. Make sure the server is running. The Base URL above should answer. If the page loaded, it is running.
  2. Get a token. Click the green Authorize button (top right), press "Log in as admin", then "Close". You are now signed in.
  3. Open an endpoint. Click any row below to expand it and read what it does.
  4. Try it. Press "Try it out", fill any fields, then "Execute". The real response appears right there.
