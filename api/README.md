# Tech Book Store API

This is the application API, separated from its Playwright suite. It uses only
Node.js built-ins at runtime.

```bash
npm start
```

Local endpoints:

- Storefront: <http://127.0.0.1:3000/techbookstore-shop.html>
- API docs: <http://127.0.0.1:3000/docs>
- Health: <http://127.0.0.1:3000/health>

The visible seeded accounts and reset behavior are intended for an isolated
local practice environment. Do not expose this server publicly without a
separate security review.
